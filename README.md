# Heaven Studio

I am building a premium one-page landing page for a Bangladeshi bespoke furniture brand called "Heaven Furniture Mart".

IMPORTANT:
I am attaching the official Company Brief PDF with this prompt. Treat that PDF as the primary source of truth for the company information, requirements, brand direction, content, colors, typography, sections, trust points, milestones, contact information, and judging criteria.

Do not invent company facts that are not supported by the brief.

The goal is NOT to build a full furniture e-commerce website.

Build ONE highly polished, conversion-focused LANDING PAGE that makes a first-time visitor understand exactly what Heaven Furniture Mart is within approximately 30 seconds.

The final result should feel like someone has entered a luxury furniture and interior-design studio — NOT like a generic online furniture shop.

==================================================

414px

Do NOT assume that a phone with a high-resolution screen has a CSS viewport width of 1080px.

Use CSS viewport width correctly.

Include:

<meta name="viewport" content="width=device-width, initial-scale=1.0">

At mobile widths:

- desktop navigation becomes hamburger
- split sections stack vertically where necessary
- hero content becomes vertical
- images remain properly cropped
- typography scales down
- padding decreases
- cards become one column where necessary
- buttons become touch-friendly
- no horizontal overflow
- no text gets cut off
- no image gets distorted

Test the layout specifically around 360–430px wide.
